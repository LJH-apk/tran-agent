## Changes made by Tran Agent

The importer converts the HTML article body to Markdown, removes website
navigation and executable scripts, normalizes tables, preserves TeX text,
and adds source URLs, retrieval timestamps and attribution. INDEX.md adds
Chinese topic routing. No claim of author endorsement is made.

Each reference has its original source URL. references/manifest.json records
retrieval time, source modification time (when available), source HTML SHA-256,
converted file SHA-256 and content length. It identifies the exact local snapshot.

Images are retained as external URLs with source captions/credits; image files
are not bundled. Individual figures can have separate reuse terms stated in
source captions. Read the source page for visual material or ambiguous formulas.

Some source pages contain only outlines or short notes. Their inclusion does
not imply that missing textbook content has been supplied.
