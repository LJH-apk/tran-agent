# 策略选择矩阵

| 症状 / 根因 | 首选策略 | 第二策略 | 不宜作为唯一措施 |
|---|---|---|---|
| 单路口轻中度不均衡 | 绿信比分配、相位优化 | 感应控制、协调 | 大规模扩路 |
| 单路口持续过饱和 | 上游控流、下游保护、排队管理 | 相位/车道功能重构 | 只延长某进口绿灯 |
| 干道停车次数高 | Offset/带宽协调 | 感应/自适应控制 | 单点独立配时 |
| 网格区域接近锁死 | 周界控制/MFD gating | 区域分区+层级控制 | 继续提高所有入口放行 |
| 快速路合流崩溃 | 匝道控制 ALINEA/协调 RM | VSL、路线诱导 | 只扩主线车道 |
| CBD 搜索停车 | 路侧停车定价与周转管理 | 装卸/网约车 curb 管理 | 只做信号优化 |
| 高峰总量长期超载 | 拥堵定价/停车/错峰/公交 | 路网优化 | 只靠信号配时 |
| 公交慢且乘客多 | TSP/公交专用或动态优先 | 预信号/间歇公交道 | 只看车辆平均延误 |
| 事故拥堵 | 事件检测、动态配时、诱导 | 可变限速/匝道控制 | 使用常发性固定方案 |
| 学校/医院局部拥堵 | 到发组织、预约/分时、临停管理 | 信号/步行保护 | 单纯扩容 |
| 路网新增连接 | 均衡/动态分配+Braaess 检查 | 定价/诱导协同 | “更多道路一定更好” |

## 选择规则
1. 先选能直接作用于根因的策略。
2. 再选控制副作用的配套策略。
3. 至少保留一个低成本、可快速部署方案作为 baseline+。
4. 对重资产扩容，必须加入诱导需求和长期均衡场景。
5. 对学习型控制，必须与 Max-Pressure/TUC/SCOOT 类强基线比较。
