# 治理原则—论文证据矩阵

用于让 Claude 从“原则”反查论文。每条原则至少有一个经典/高影响锚点；精确结论仍需读对应论文卡片和原文。

| 治理原则 | 论文锚点 | 决策含义 |
|---|---|---|
| 先诊断机理，再选措施 | `F06,S06,M01` | 平均速度只是症状；要识别瓶颈、排队、spillback、需求峰值与控制失配。 |
| 局部优化必须服从下游存储约束 | `S05,S11,M05` | 上游放行过多会把延误变成下游回溢。 |
| 扩容必须检查均衡与诱导需求 | `F01,F02,D01` | 新容量会改变路径与长期需求，不能用静态流量差直接估算长期收益。 |
| 高峰治理包含出发时刻管理 | `F04,F05,D09` | 高峰不是固定需求；价格和制度会改变出发时刻。 |
| 价格治理必须做公平与可接受性评估 | `D09,D10,D11,D08` | 效率提升不自动意味着分配公平。 |
| 停车是道路拥堵的一部分 | `D04,D12,D13` | 巡游、违停和上下客会降低有效容量并增加扰动。 |
| 过饱和信号网络优先防 spillback | `S02,S03,S04,S05` | 减少单路口延误不如维持网络可流动性重要。 |
| 成熟自适应系统是 AI 的强基线 | `S07,S08,S09,S06` | AI 比较必须面对真实的 adaptive control lineage。 |
| MFD 周界控制的目标是保护临界积累量 | `M01,M02,M05` | 核心区超临界后继续放车可能降低整体产出。 |
| MFD 分区必须控制异质性 | `M04,M06,M07` | 单一平均密度在高度异质网络中可能失真。 |
| 匝道计量是保护瓶颈而非惩罚匝道 | `R01,R07,R08` | 在 breakdown 前限制流入可避免 capacity drop。 |
| 匝道控制要设置地面路网外溢约束 | `R05,R08` | 主线收益不能以匝道队列无限增长为代价。 |
| VSL 要做服从率敏感性 | `R03,R04` | 100% 服从的仿真通常过于乐观。 |
| 公交优先以人而非车辆为目标 | `T02,T06,T08` | person-delay / passenger throughput 能避免只服务小汽车。 |
| 公交优先应条件化、协调化 | `T06,T07,T05` | 晚点程度、客流和下游状态应决定优先强度。 |
| 路径诱导必须二次检查新瓶颈 | `F09,F10,F11` | 用户响应会改变原先“最短路”的优势。 |
| RL 必须击败 Max-Pressure/TUC/成熟控制 | `S05,S02,A01,A08` | 弱基线无法证明工程价值。 |
| RL 需要 OOD、噪声和 sim-to-real 测试 | `A09,A10,A12` | 训练分布内成绩不足以支持现场治理。 |
| 真实案例迁移的是机制而不是参数 | `D09,D10,D11,R07` | 费率、阈值和控制参数必须本地校准。 |
| 评价要看网络、可靠性与尾部风险 | `S06,I01,I02` | 平均值可能掩盖最大排队、边界拥堵和少数群体损失。 |

## 使用要求

- 推荐方案时至少引用一条与目标机理直接对应的原则。
- 若策略只有 AI/仿真证据，必须同时给出传统控制基线和证据等级。
- 若原则对应论文的场景与当前任务不一致，标记“类比证据”，不要写成直接验证。
