# 拥堵机理 → 策略 → 证据等级决策表

| 机理 | 首选干预 | 次选干预 | 必看副作用 | 主要证据类型 |
|---|---|---|---|---|
| 交叉口绿信比分配不匹配 | 配时优化 | 感应/自适应 | 侧向排队、行人 | 工程/仿真/实地 |
| 下游存储不足导致 spillback | 下游约束/pressure | 周界控制 | 上游等待转移 | 理论+仿真+部分实地 |
| 核心区 accumulation 超临界 | MFD gating | 分区协调 | 边界排队 | 理论+实证 MFD+仿真 |
| 高峰总需求过大 | 价格/错峰/方式转移 | 容量小改造 | 公平、绕行 | 经济理论+城市实证 |
| 停车巡游 | 路缘定价/信息 | 增加周转 | 商户/步行影响 | 理论+停车实证 |
| 快速路合流 breakdown | ramp metering | VSL/协调控制 | 匝道外溢 | 现场+控制理论 |
| 公交晚点且客流高 | 条件 TSP | 专用/动态公交道 | 小汽车侧向延误 | 实地+仿真 |
| 事故造成短期容量损失 | 事件管理+受控分流 | 临时信号方案 | 二次拥堵 | 运营数据+仿真 |
| 网络路线不均衡 | 信息/诱导+DTA | 价格 | 新瓶颈 | 均衡理论+DTA |
| 信号策略对随机需求适应差 | 自适应/MPC | RL | 稳定、安全、域偏移 | 控制+仿真+有限实地 |

## 决策分层

### Level 0：低成本运营
标线、违停管理、相位参数、事件检测、公交站组织。

### Level 1：控制系统
协调信号、匝道控制、VSL、TSP、周界控制。

### Level 2：需求与价格
停车、路价、错峰、预约、拥堵收费。

### Level 3：空间与基础设施
路权重分配、公交专用、瓶颈改造、网络连接调整。

### Level 4：长期土地使用/多模式
TOD、职住结构、公共交通供给、慢行网络。

Agent 应优先说明为何从某一层开始，而不是每次都推荐 Level 3 扩容。
