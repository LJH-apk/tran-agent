# ITSAC 交通仿真智能体治理 Playbook

## Agent 应回答的不是“配时是多少”而是“为什么这样治理”

### 任务 1：常发性拥堵
诊断：需求/供给/控制/下游。
候选：信号优化、车道重构、需求管理、公交优先。
验证：峰值、多随机种子、最大排队与外溢。

### 任务 2：关键瓶颈
定位“最先失稳”的位置，建立瓶颈上游输入与下游接收关系。
候选：上游 gating、局部容量改善、下游清空、路径引导。

### 任务 3：排队溢出
首要目标不是平均延误，而是把队列压回储存空间内。采用 spillback-aware signal / max-pressure / queue balancing。

### 任务 4：通勤高峰
把错峰、定价、停车和公交纳入方案，不限于信号控制。

### 任务 5：学校/医院
优先考虑到发组织、临停、网约车上下客、行人安全和短时需求峰。

### 任务 6：枢纽集散
按列车/航班/活动波次建需求，不使用平滑平均流；考虑公交、出租、网约车、步行交织。

### 任务 7：施工改扩建
构建容量下降场景 + 分流场景 + 恢复场景；监控次生瓶颈。

## 报告结构
1. 现状证据。
2. 拥堵机理图。
3. 文献依据。
4. 三档方案：低成本/中等/结构性。
5. 仿真实验。
6. KPI 对比。
7. 风险与实施顺序。
