# 一体化交通控制

## 为什么需要集成
信号、匝道控制、导航、公交优先、周界控制可能互相抵消。例：导航把车导入某干道，而信号控制正在限制该方向进入核心区。

## 分层架构
### 战略层
需求管理、路权、价格、区域积累目标。
### 战术层
信号计划、周界流量、匝道放行、公交优先、VSL。
### 操作层
秒级/周期级动作执行与安全约束。

## 共同目标
- total time spent / total delay。
- person-delay。
- network completion rate。
- spillback risk。
- emissions + equity penalty。

## 冲突解析
当两个控制器动作冲突时，优先级建议：
1. 安全。
2. 防止不可恢复的网格锁死/回溢。
3. 公交/应急硬约束。
4. 网络效率。
5. 局部舒适性。

## Agent 编排
每个工具调用都应写：状态输入、作用范围、动作、预期机制、约束、观察到什么结果后继续/撤回。
