# 道路空间与路网设计治理

## 1. 扩容不是默认答案
Wardrop、Braess、诱导需求文献共同提示：供给改变会触发路线和需求重新均衡。新增链路、放开转向、加车道必须做网络反事实。

## 2. 车道功能重构
- 专用左/直/右与共享车道。
- 潮汐车道、可变车道。
- 动态路缘：停车、装卸、公交、网约车时段切换。
- 公交道/高乘载车道。

## 3. 道路空间再分配
对步行、骑行、公交的再分配可能压缩一般机动车容量，但并不必然造成一比一交通转移。应考虑改时、改道、改方式、取消出行等行为响应。

## 4. 路网连通与 Braess 检查
新增连接后：
1. 重新求 UE / DTA。
2. 比较总旅行时间和关键 OD。
3. 检查是否出现新的短路径诱导大量流量。
4. 尝试收费/限行/定向组织作为补救。

## 5. 容量设计的鲁棒性
不要只在平均需求下设计。至少测试：+10%、+20%需求；转向比例偏差；一个关键车道/路段失效；公交/行人高峰。

## 6. 网络设计目标
道路网络设计应同时考虑：总成本、可靠性、可达性、公交服务、建设成本、环境、公平和实施约束。
