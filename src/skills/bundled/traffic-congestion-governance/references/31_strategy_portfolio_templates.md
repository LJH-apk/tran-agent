# 组合治理方案模板

## 模板 A：过饱和信号走廊

**诊断**：关键交叉口 v/c 高；出口存储不足；队列跨周期且向上游传播。

**组合**：
- 短期：清除路缘干扰 + 调整相位/绿信比；
- 中期：走廊协调 + 下游存储约束；
- 高峰：公交优先采用条件式；
- 网络级：必要时用 Max-Pressure/TUC/MPC 防止 spillback；
- 需求端：大型发生源错峰/预约。

**评价**：TTT、吞吐、最大排队、spillback 分钟数、公交人均延误、侧向道路延误。

## 模板 B：中心区长期拥堵

**诊断**：需求长期接近/超过可用道路空间，停车巡游和路缘冲突显著。

**组合**：
- curb management；
- 停车定价/周转；
- 公交优先；
- 适度道路收费/需求管理；
- 步行骑行短途替代；
- MFD 周界控制用于保护核心区临界积累量。

**评价**：person throughput、可达性、核心区 accumulation、停车搜索、收费/停车公平性。

## 模板 C：快速路合流瓶颈

**组合**：ALINEA → 协调匝道计量 → VSL/MPC → 事件管理；配套匝道排队上限与地面路网保护。

## 模板 D：事故/施工

**组合**：快速检测 → 容量估计 → 受控分流 → 信号临时方案 → 公交/应急优先 → 清障 → 残余队列恢复控制。

## 模板 E：学校/医院周边

**原则**：安全和行人优先高于车辆吞吐。采用上下客分区、到离校错峰、步行空间、公交接驳与停车管理；严禁只以机动车平均速度作为唯一目标。
