# 动态交通分配、路径诱导与“把拥堵挪走”的风险

## 1. 静态与动态的分界

当治理方案影响的只是长期平均路径，静态 UE 可用于初筛；当方案涉及事件、分时收费、临时封闭、潮汐交通或队列回溢，必须考虑动态网络加载与 DTA。

## 2. 三个不能忽略的行为响应

- 路线选择：新的最短路会吸引更多交通；
- 出发时刻：高峰控制会产生肩峰或提前/延后出行；
- 是否出行/方式选择：长期策略会改变需求总量与模式分担。

## 3. Route guidance 治理原则

### 原则 A：不要只给每个人当前最短路
个体最短路的同步推荐可能造成新的局部拥堵。需要预测拥堵与网络均衡。

### 原则 B：控制转移量
采用分批诱导、概率诱导或容量约束，避免把替代路一次性灌满。

### 原则 C：保护脆弱道路
居民区、小学周边、窄路即使时间更短，也可能因安全/噪声/公平约束不应成为大规模分流通道。

### 原则 D：事件结束后的恢复
事故清除不等于系统马上恢复。残余队列和重新路由会产生滞后，需要看恢复时间。

## 4. 仿真评价

至少设计：无诱导、当前最短路诱导、容量约束诱导、系统最优近似四组。比较全网 TTT、完成出行数、最差 5% 路段、居民区流量、最大排队和恢复时间。

## 5. Agent 规则

IF 方案包含“分流” THEN 强制执行二次拥堵检查。
IF 替代路径有低容量瓶颈 THEN 给出最大可接受转移流量而不是笼统说“引导车辆绕行”。
IF 事件持续时间短于网络重新均衡时间 THEN 警惕过度诱导造成反作用。
