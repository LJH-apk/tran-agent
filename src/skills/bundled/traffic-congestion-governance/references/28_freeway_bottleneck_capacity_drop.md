# 快速路瓶颈、容量下降与走廊控制

## 1. 治理目标不是“让匝道车尽快进入”

当主线接近临界状态时，少量额外流入可能触发交通崩溃，随后瓶颈排出能力出现 capacity drop。此时最佳策略可能是暂时在匝道上储存一部分队列，以保护主线高吞吐状态。

## 2. 机制链

需求接近容量 → 合流扰动/换道 → 局部速度下降 → 密度升高 → breakdown → 排出能力下降 → 主线队列扩大 → 上游匝道/交织区进一步受扰。

## 3. 控制组合

### ALINEA / 本地匝道计量
用下游占有率反馈调节进入率，简单稳健，是 RL/MPC 应该击败的强基线。

### 协调匝道计量
当多个匝道共享瓶颈时，要分配“排队负担”，防止某个匝道溢出到地面道路。

### VSL
目的不是单纯降速，而是平滑流入、减小速度差、延迟/避免 breakdown。效果对执行率和驾驶员服从高度敏感。

### 主线流量控制与车道管理
可通过可变限速、动态车道、合流控制等实现，但必须评估安全、法规和驾驶行为。

## 4. 公平与外部性

匝道计量的主线收益不能以无限制增加支路排队为代价。至少设置 ramp queue cap，并监测排队是否阻塞城市道路或公交。

## 5. Agent 规则

IF 瓶颈存在明显 breakdown + capacity drop THEN 优先考虑“预防崩溃”而非“崩溃后加速排队消散”。
IF 匝道队列接近存储上限 THEN 协调控制必须让渡部分主线效率以保护地面路网。
IF VSL 仿真假设 100% 服从 THEN 标记为乐观情景并增加低服从敏感性测试。
