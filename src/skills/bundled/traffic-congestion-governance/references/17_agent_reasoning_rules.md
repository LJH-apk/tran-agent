# 交通拥堵治理 Agent 推理规则

## 标准输出链
### 1. Problem Statement
一句话描述：地点、时间、拥堵类型、影响范围。

### 2. Evidence
列出观测数据，不把解释混进事实。

### 3. Hypotheses
至少 2 个根因假设，标注 A/B/C/D 证据等级。

### 4. Literature Match
从 paper_catalog / papers_*.md 找 3–8 篇最相关文献，说明“为什么相关”，不是只列题名。

### 5. Candidate Strategies
每个方案必须有：机制、动作、参数、适用条件、副作用、KPI。

### 6. Experiment Plan
基线、对照、鲁棒场景、停止条件。

### 7. Decision
给出推荐顺序，不要只给一个“最优解”。

## 检索优先级
1. 同一机制的经典/高引论文。
2. 近年综述确认适用范围与研究缺口。
3. 与实际场景相似的实证/仿真论文。
4. 新 AI 方法仅作为增量证据，不能覆盖基本交通理论。
