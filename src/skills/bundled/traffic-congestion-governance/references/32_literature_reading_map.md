# 文献阅读地图：从经典理论到现代 Agent

## 路线 1：为什么“修路”不一定治堵
Wardrop → Braess → induced demand (Duranton & Turner) → disappearing traffic (Cairns et al.) → network design review。

## 路线 2：拥堵为什么需要价格
Vickrey → Small → Arnott/de Palma/Lindsey → de Palma & Lindsey review → Stockholm/London field evidence → equity pricing。

## 路线 3：如何控制信号网络
SCOOT/SCATS → OPAC/RHODES → TUC → rolling-horizon QP → Max-Pressure → PressLight/CoLight/FRAP。

## 路线 4：如何防止城市核心区 gridlock
Daganzo 2007 → Geroliminis & Daganzo 2008 → analytical MFD → heterogeneity/hysteresis → partitioning → perimeter control → hierarchical control。

## 路线 5：快速路瓶颈治理
CTM → ALINEA → ramp-metering overview → Cassidy merge field evidence → Gomes/Horowitz optimization → coordinated metering → MPC+VSL。

## 路线 6：公交优先不是“公交永远绿灯”
Intermittent bus lane → conditional/coordination TSP → multimodal signal control → connected-vehicle TSP → person-delay objectives。

## 路线 7：RL 如何避免论文型自嗨
MARLIN → IntelliLight → PressLight → CoLight/FRAP → MetaLight → CityFlow/LibSignal → sim-to-real / robustness literature。

## 阅读顺序规则

先读理论锚点，再读治理实证，再读优化算法，最后读 AI。若反过来，很容易把“模型性能”误认为“交通治理效果”。
