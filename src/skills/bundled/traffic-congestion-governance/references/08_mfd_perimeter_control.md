# MFD、区域分区与周界控制

## 1. MFD 思路
对相对同质区域，用平均积累 n 与网络生产/流量 P(n) 描述整体状态。通常存在临界积累 n*，接近 n* 时完成率较高；超过后可能进入过饱和下降区。

## 2. 治理目标
不是“让所有入口都尽快放行”，而是把保护区积累维持在高生产率附近，防止网格锁死。

## 3. 什么时候适合
- 城市核心区/片区明显过饱和。
- 有边界信号可调。
- 区域内部状态可观测。
- MFD 散点相对稳定，或可通过分区降低异质性。

## 4. 什么时候不适合直接上
- 区域极度异质。
- 边界外无排队存储。
- 大量穿越流没有替代路径。
- 关键瓶颈是单点物理阻塞而非区域积累。

## 5. 分区
按交通状态同质性+空间连通性，而不是行政边界。高异质网络可分为多个 reservoir，再做层级控制。

## 6. 周界控制副作用
- 外围排队增加。
- 邻区绕行。
- 公交/应急车辆受影响。
- 不同方向公平性问题。
因此需同时约束边界最大队列和最低服务率。

## 7. Agent 规则
若核心区平均速度下降且积累超过临界、多个内部路口回溢、增加绿灯无效，则优先测试“控进入”而不是“继续放入”。
