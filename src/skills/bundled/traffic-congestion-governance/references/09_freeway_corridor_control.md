# 快速路与高速走廊治理

## 1. 核心现象：交通崩溃
合流区接近临界状态时，小扰动即可导致速度骤降和容量损失。治理的关键是避免/延缓 breakdown，而不是等堵死后再疏散。

## 2. 匝道控制
### ALINEA 逻辑
利用下游占有率反馈调节匝道放行率，使主线运行在目标附近。
### 协调匝道控制
多个入口共享主线容量时，需要网络级优化/协调，同时管理各匝道队列。

## 3. 可变限速 VSL
更强的证据常在安全与流态平滑；是否提高容量要看当地交通行为和控制算法。不能把“安全有效”自动等同于“通行能力提高”。

## 4. 路径诱导
事故或多瓶颈走廊可联合 VMS/导航做分流，但必须预测被分流道路的剩余容量。

## 5. 集成控制
RM + VSL + route guidance 可用 MPC 等统一目标优化。核心 KPI 是 total time spent、throughput、queue constraints、recovery time。

## 6. 约束
- 匝道最大队列与地面路网回溢。
- 最低放行公平性。
- VSL 驾驶员服从率。
- 事故占道比例与恢复时间。
